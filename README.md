# Vortex Emu

Vortex Emu is a new emu based on winlator, designed to run Windows games, it supports 32-bit and 64-bit games.







# Requirements

minimum (WineD3D only

gpu: adreno 530 or mali t880 
vulkan version: 1.0 
ram: 2 or 1GB

Recommended

gpu: adreno 730 or mali g710
Vulkan version: 1.1-1.3
Ram: 4GB+




# installation

get apk here at [Releases](https://github.com/Disco-sys/Vortex-emu/releases)
and download the latest apk.
